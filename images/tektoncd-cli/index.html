utility 0.45.0 Upstream ↗

CLI for interacting with Tekton Pipelines

Get this image

Pull from registry

docker pull ghcr.io/nix-containers/images/tektoncd-cli:latest

Build from source (current version: 0.45.0)

nix build github:nix-containers/images#tektoncd-cli

Load into local Docker

nix build github:nix-containers/images#load-tektoncd-cli-to-docker && ./result/bin/load-tektoncd-cli-to-docker

Pull from registry

docker pull ghcr.io/nix-containers/images/tektoncd-cli-dev:latest

Build from source

nix build github:nix-containers/images#tektoncd-cli-dev

Load into local Docker

nix build github:nix-containers/images#load-tektoncd-cli-dev-to-docker && ./result/bin/load-tektoncd-cli-dev-to-docker

The -dev variant bundles the same software with a shell and common debug tools. May not yet be built for every image — file an issue if you'd like one added.

Provides a CLI for interacting with Tekton - tkn

The Tekton Pipelines cli project provides a CLI for interacting with Tekton! For your convenience, it is recommended that you install the Tekton CLI, tkn, together with the core component of Tekton, Tekton Pipelines.
