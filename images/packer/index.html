Machine image builder

Get this image

Pull from registry

docker pull ghcr.io/nix-containers/images/packer:latest

Build from source (current version: 1.15.4)

nix build github:nix-containers/images#packer

Load into local Docker

nix build github:nix-containers/images#load-packer-to-docker && ./result/bin/load-packer-to-docker

Pull from registry

docker pull ghcr.io/nix-containers/images/packer-dev:latest

nix build github:nix-containers/images#packer-dev

Load into local Docker

nix build github:nix-containers/images#load-packer-dev-to-docker && ./result/bin/load-packer-dev-to-docker

The -dev variant bundles the same software with a shell and common debug tools. May not yet be built for every image — file an issue if you'd like one added.
