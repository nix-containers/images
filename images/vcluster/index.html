vcluster

utility 0.35.1 Upstream ↗

Create fully functional virtual Kubernetes clusters

Get this image

Pull from registry

docker pull ghcr.io/nix-containers/images/vcluster:latest

Build from source (current version: 0.35.1)

nix build github:nix-containers/images#vcluster

Load into local Docker

nix build github:nix-containers/images#load-vcluster-to-docker && ./result/bin/load-vcluster-to-docker

Pull from registry

docker pull ghcr.io/nix-containers/images/vcluster-dev:latest

Build from source

nix build github:nix-containers/images#vcluster-dev

Load into local Docker

nix build github:nix-containers/images#load-vcluster-dev-to-docker && ./result/bin/load-vcluster-dev-to-docker

The -dev variant bundles the same software with a shell and common debug tools. May not yet be built for every image — file an issue if you'd like one added.
