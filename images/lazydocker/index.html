Terminal UI for Docker and docker-compose

Get this image

Pull from registry

docker pull ghcr.io/nix-containers/images/lazydocker:latest

Build from source (current version: 0.25.2)

nix build github:nix-containers/images#lazydocker

Load into local Docker

nix build github:nix-containers/images#load-lazydocker-to-docker && ./result/bin/load-lazydocker-to-docker

Pull from registry

docker pull ghcr.io/nix-containers/images/lazydocker-dev:latest

Build from source

nix build github:nix-containers/images#lazydocker-dev

Load into local Docker

nix build github:nix-containers/images#load-lazydocker-dev-to-docker && ./result/bin/load-lazydocker-dev-to-docker

The -dev variant bundles the same software with a shell and common debug tools. May not yet be built for every image — file an issue if you'd like one added.
