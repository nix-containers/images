DevContainer CLI for development containers with VS Code

Get this image

Pull from registry

docker pull ghcr.io/nix-containers/images/devcontainer:latest

Build from source (current version: 5.3p9)

nix build github:nix-containers/images#devcontainer

Load into local Docker

nix build github:nix-containers/images#load-devcontainer-to-docker && ./result/bin/load-devcontainer-to-docker

Pull from registry

docker pull ghcr.io/nix-containers/images/devcontainer-dev:latest

Build from source

nix build github:nix-containers/images#devcontainer-dev

Load into local Docker

nix build github:nix-containers/images#load-devcontainer-dev-to-docker && ./result/bin/load-devcontainer-dev-to-docker

The -dev variant bundles the same software with a shell and common debug tools. May not yet be built for every image — file an issue if you'd like one added.
