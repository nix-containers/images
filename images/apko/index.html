Build OCI images using APK directly without Dockerfile

Get this image

Pull from registry

docker pull ghcr.io/nix-containers/images/apko:latest

Build from source (current version: 1.2.21)

nix build github:nix-containers/images#apko

Load into local Docker

nix build github:nix-containers/images#load-apko-to-docker && ./result/bin/load-apko-to-docker

Pull from registry

docker pull ghcr.io/nix-containers/images/apko-dev:latest

Build from source

nix build github:nix-containers/images#apko-dev

Load into local Docker

nix build github:nix-containers/images#load-apko-dev-to-docker && ./result/bin/load-apko-dev-to-docker

The -dev variant bundles the same software with a shell and common debug tools. May not yet be built for every image — file an issue if you'd like one added.
